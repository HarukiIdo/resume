## 職務要約

2023年4月に株式会社ディー・エヌ・エーへ新卒入社し、新卒研修を経て IT本部 IT戦略部 システム基盤グループに所属。全社で利用するサービスやツールの開発・運用・管理を担当しました。

学生時代から複数企業でインターン・副業を経験し、インフラ運用の自動化、バックエンド API 開発からフロントエンドへの繋ぎ込み・画面開発、モバイルアプリの機能開発などを担当してきました。

### 株式会社ビルディット

- **期間:** 2021年9月 - 2022年5月
- **区分:** インターン（Stockr 開発チーム）
- **業務内容:**
  - 振り返り習慣化アプリ「Stockr」の機能開発・保守・リリース
  - 法人向け振り返りアプリ「みまもりStockr」の立ち上げから機能開発

**主な取り組み**

1. **環境の切り替えをコマンドで実現（2022年3月）**
   - 背景: 従来は FLAVOR という環境変数を用意しソースコードを都度変更して開発・ステージング・本番環境を切り替えており、Firebase Local Emulator Suite を使うローカル開発体制への移行後は、ビルドのたびのソースコード変更と PR 前の戻し作業が必要となり、戻し忘れや別環境への接続などのトラブルが発生していた
   - アクション: Dart Define というビルド時のコマンドで環境分けが可能になるツールを導入
   - 結果: 各開発者が開発に関する関心事に集中できるようになり、開発効率が向上

2. **法人向け「みまもりStockr」の設定画面の UI 開発を担当（2021年12月 - 2022年2月）**
   - 概要: Stockr への「みまもり機能」の実装を目的として、既存サービスの問題点を刷新し、1から開発。上司が部下の“ストック”をフォロワーとして“みまもる”ことができ、部下が「話したい！」というサインを付けると、上司が「見たよ！」というサインを返せる確認・承認のやり取りを通じて信頼感を構築する機能
   - 学んだこと: アーキテクチャの考え方（MVVM からクリーンアーキテクチャベースへの変更）、Atomic Design と Storyboard を活用したコンポーネント開発、ユニットテストの実装

3. **Stockr の「テーマ設定」機能の開発（2021年11月 - 2021年12月）**
   - 概要: 年内 10,000 ダウンロード達成を目標とした施策の一つとして、開発チーム 3人で開発。個人の学びのテーマを最大5つまで登録し、ストックする一つの気づきに対して一つのテーマを設定できる機能
   - 成果: 目標であった年内 10,000 ダウンロードを達成
